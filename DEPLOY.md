# Деплой фронтенда Tez Jumush

## 🚀 Быстрый деплой на Railway

### Предварительные требования
- ✅ Бэкенд уже развернут на Railway
- ✅ MySQL настроен и работает
- ✅ API эндпоинты доступны

### Шаг 1: Настройка переменных окружения

В Railway Dashboard для фронтенда добавьте:
```env
VITE_API_URL=https://your-backend-app.railway.app/api
```

**Замените `your-backend-app` на реальный URL вашего бэкенда!**

### Шаг 2: Подключите репозиторий
1. Создайте новый проект в Railway
2. Подключите ваш Git репозиторий
3. Выберите папку `tez-jumush-frontend`

### Шаг 3: Автоматический деплой
Railway автоматически:
1. Установит зависимости (`npm install`)
2. Соберет проект (`npm run build`)
3. Запустит preview сервер (`npm run preview`)

### Шаг 4: Проверка
После успешного деплоя:
- Откройте URL фронтенда
- Проверьте что вакансии загружаются
- Протестируйте регистрацию/вход

## 🛠 Локальная разработка

### С продакшен API:
```bash
# Использует .env с продакшен URL
npm run dev
```

### С локальным API:
```bash
# Обновите .env на локальный URL
echo "VITE_API_URL=http://localhost:4000/api" > .env
npm run dev
```

### Переключение между режимами:
```bash
# Для продакшен API
cp .env.production .env

# Для локального API  
cp .env.local .env
```

## 📦 Структура файлов

```
.env.local          # Локальный API (http://localhost:4000/api)
.env.production     # Продакшен API (https://your-app.railway.app/api)
.env               # Текущая конфигурация
railway.json       # Конфигурация Railway
```

## 🔧 Отладка проблем

### Фронтенд не загружается:
1. Проверьте логи Railway
2. Убедитесь что `npm run build` успешен
3. Проверьте переменные окружения

### API не работает:
1. Проверьте URL в `VITE_API_URL`
2. Убедитесь что бэкенд доступен
3. Проверьте CORS настройки

### 404 ошибки на маршрутах:
1. Настройте redirects в Railway
2. Или используйте hash routing в Vue

## 🌐 Финальная проверка
